# Overwhelm scaffold

This student overloads on long prose. He still needs enough context to think
on a test. Notes are a legend for the maps, not a second textbook and not a
thin recap that drops half the lecture checklist.

## Two study paths

**First contact:** orient with the Mermaid map in GoodNotes **Map/**, read one
Core group in **Notes/**, then attempt its Practice questions in Obsidian
**Reading view**. Use optional Why it works only when Core is not enough.
Official Quiz why stays on disk. After the alternatives in a contrast are each
understood, use the TD sort maps in **Retrieval/**.

**Return session:** begin closed-book. Answer a Practice item or reconstruct the
relevant map branch before reopening anything. Check against Map/Core, repair
only the missed decision, then try a different item. On Day 7, redraw a TD sort
map from memory before checking it. A map is an orientation aid on first
contact and a feedback source later; looking at it first on every return turns
retrieval into recognition.

Work through one short group at a time and return on later days; a content-sized
bank is not a single sitting. Practice is the study engine, not an HTML page or
the book quiz.

## Rules

- If it fits in six words, it is a map node. Longer stays in notes.
- Contrast is a real table: SRS vs equal-person chance; stratified vs cluster;
  observational vs experiment; lurking vs confounding; sampling vs nonsampling
  error.
- TEST MOVE = what to do when this shows up on an exam. One line.
- Do not recopy the book. Restate. If a line could be pasted from the PDF,
  rewrite it.
- Screenshots may be the section source. Read them in place. They earn map
  nodes. Do not copy them into Chapter-Kits. Later screenshots can fill gaps in that same section after ledger evidence is added.
- Official answers only when the page printed them.
- Do not fill graded homework. Teach the method with a *different* example.
- If he could copy the kit onto the assignment without deciding anything, the
  kit crossed the line.
- Do not ship a per-section interactive HTML quiz. Folded callouts in the vault
  are the iPad path.
- Add cues after a demonstrated miss and remove them after success. Use actual
  attempts to adapt support, never a visual/auditory/reading/kinesthetic label.

## Maze guard

Do not add another app, notebook, export, calendar, or question bank unless it
has a distinct job, appears in the stated study order, and does not duplicate
Map, Core, Practice, or `study-log.md`. Audio, an ELI5 page, or reminders may be
made when the user explicitly asks, but they are optional views—not a new
canonical source and not a default part of every chapter.

## Homework that is not in the chapter

Name it a **bridge tool**. Work a tiny unrelated example. Send him back to his
own paper.

## Preserve the explanation

Core is the entry point, not a word-count ceiling for the whole kit. Cover
every earned objective. If the student cannot explain a decision from that
heading, add a table or one small example rather than more compressed labels.
Do not require reading all optional detail before trying Practice.md. Use
consistent headings and tell the student exactly where to return after a miss.
